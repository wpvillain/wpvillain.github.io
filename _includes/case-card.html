{%- comment -%} Renders one post as a "case file" report card. Usage: {% include case-card.html post=post number=n %} - include.post : the post object (required) - include.number : case number to display (optional; falls back to a hash of the title so cards still look right on tag pages where a running index isn't available) {%- endcomment -%} {%- assign p = include.post -%} {%- assign cat = p.case_category | default: "general" -%} {%- assign status = p.case_status | default: "documented" -%} {%- assign case_no = include.number | default: "—" -%}
Case No. {{ case_no }} {{ cat | capitalize }} {{ status | capitalize }}

{{ p.title | escape }}

{%- if p.excerpt %}

{{ p.excerpt | strip_html | strip_newlines | truncate: 160 }}

{%- endif %}
{{ p.date | date: "%b %-d, %Y" }} {%- if p.tags and p.tags.size > 0 %} · {%- for tag in p.tags limit: 4 %} {{ tag }} {%- endfor -%} {%- endif %}
